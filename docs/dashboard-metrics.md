# تعريف مؤشرات لوحات Smart Diet v2

تُحسب المؤشرات من الصفوف التي يستطيع الدور الحالي قراءتها وفق RLS. لا تُنشأ أرقام تقديرية ولا تُستخدم بيانات تجريبية لملء الفراغات.

## لوحة صاحب المنصة (/owner)

| المؤشر | التعريف | المصدر |
|---|---|---|
| إجمالي العيادات | عدد صفوف `clinics` التي أعادتها قاعدة البيانات للمالك | `clinics` |
| اشتراكات نشطة | عيادات غير موقوفة إداريًا واشتراكها `active` | `clinics.status`, `clinic_subscriptions.status` |
| فترة السماح | عيادات غير موقوفة واشتراكها `grace` | `clinic_subscriptions.status` |
| منتهية/بلا اشتراك | عيادات غير موقوفة واشتراكها `expired` أو لا يوجد صف اشتراك | `clinic_subscriptions` |
| موقوفة إداريًا | `clinics.status = suspended`؛ لا تُدمج مع انتهاء الاشتراك | `clinics.status` |
| تنتهي خلال 30 يومًا | اشتراك نشط شهري/سنوي وتاريخ انتهائه من اليوم إلى 30 يومًا | `clinic_subscriptions.expires_at` |
| طلبات دفع معلقة | سجلات `payments` التي لا تحمل `reviewedAt` | `clinic_subscriptions.payments` |
| المدفوعات المعتمدة لآخر 6 أشهر | مبالغ السجلات التي تحمل `reviewedAt` ولا تحمل ملاحظة رفض، بحسب شهر المراجعة | `clinic_subscriptions.payments` |

**قيد مالي:** هذا المؤشر يعكس سجلات طلبات الدفع التي تمت مراجعتها واعتمادها داخل سجل JSONB، وليس دفترًا محاسبيًا مستقلًا. التجديد اليدوي دون سجل دفع لا يدخل فيه. لا يُستخدم الرقم لإصدار تقارير مالية قانونية.

## لوحة مدير العيادة (/platform، role=admin)

| المؤشر | التعريف | المصدر |
|---|---|---|
| مرضى العيادة | عدد صفوف المرضى في نطاق clinic_id | `patients` |
| الأطباء | عدد ملفات `profiles` بدور coach داخل العيادة | `profiles` |
| لديهم سجل خطة | مرضى لديهم قيمة مسجلة في `patients.plan` | `patients.plan` |
| بلا طبيب معيّن | مرضى لا يشير `invited_by` لديهم إلى طبيب موجود ضمن أطباء العيادة | `patients.invited_by`, `profiles` |

## لوحة الدكتور (/platform، role=coach)

| المؤشر | التعريف | المصدر |
|---|---|---|
| عملائي | المرضى الذين تظهر لهم نتيجة `listDoctorPatients(clinicId, uid)` فقط | `patients.invited_by` |
| لديهم سجل خطة | عملائي الذين لديهم `patients.plan` | `patients.plan` |
| بلا سجل خطة | عملائي الذين لا توجد لهم خطة سحابية بعد | `patients.plan` |

لا تُعرض مؤشرات التزام أو تحسن وزن أو نتائج سريرية على مستوى اللوحة قبل تعريف الفترة الزمنية وحالات غياب السجل ومراجعة المحتوى من مختص سريري مؤهل.
